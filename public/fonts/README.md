# Site typography

English: Source Serif 4, self-hosted variable WOFF2 (Latin and Latin Extended).
Selected settings: headings 500, body 500 / 18px, optical sizing enabled.
Chinese: existing SourceHanSerifCN-subset.woff2, unchanged.
Navigation, captions and schedule metadata retain their compact type sizes.

Source Serif 4 assets originate from the Google Fonts CSS API. The SIL Open Font
License is included in source-serif-4-OFL.txt.
Upstream: https://github.com/adobe-fonts/source-serif

The font comparison page shares these assets; other candidates remain in preview/.
